Hunter's Mirror

Project handoff for a Bloodborne character creation assistant that estimates in-game slider values from an uploaded face image.

Project Type Browser-based web tool
Current State Working prototype
Primary Goal Photo to Bloodborne sliders

What We Are Attempting To Create

The goal is to create a useful tool for Bloodborne fans who want to recreate a real face, celebrity face, fictional character, or reference image inside Bloodborne's PS4 character creator.

A user uploads a clear face image. The app analyzes the face and produces a full character creation sheet with Bloodborne-style slider values and manual menu choices. The user can then enter those values in the game to create the closest possible match.

Important product direction: this should become a serious community tool, not a toy demo. The long-term value comes from improving slider accuracy through real Bloodborne calibration data and presenting the output in a format players can easily use.

What Exists So Far

  • Vite browser app with a polished single-page interface.
  • Local image upload and drag/drop support.
  • MediaPipe Face Landmarker integration for browser-side facial analysis.
  • Estimated Bloodborne slider sheet generated from face proportions.
  • Confidence score and extracted measurement summary.
  • JSON and CSV export buttons.
  • Calibration preset button for checking the full sheet without uploading a photo.
  • Expanded Bloodborne menu coverage: Basic Setup, Face Presets, Scale Adjustment, Face Shape, Skin Color/Makeup, Hair/Facial Hair, Pupils, Tattoo/Mark/Glasses, and Tweak Tattoo/Mark.

Current Technical Approach

Area Implementation
Frontend Plain JavaScript, HTML, CSS, bundled with Vite.
Face Detection MediaPipe Tasks Vision Face Landmarker loaded from CDN.
Image Handling Client-side only. Uploaded photos are not sent to a server.
Slider Mapping Hand-authored heuristic mapping from 2D facial landmark ratios to Bloodborne 0-255 slider values.
Export Generated values can be exported as JSON or CSV.

Known Limitations

  • The current estimator uses 2D face landmarks, not Bloodborne's internal 3D face mesh.
  • Depth-related values like protrusion, forehead depth, and some nose/jaw profile settings are rough estimates.
  • Skin tone, hair, brows, beard, pupils, makeup, tattoo/mark, and glasses are mostly manual placeholders right now.
  • Accuracy must be validated by entering generated values into Bloodborne and comparing screenshots.
  • The app currently depends on MediaPipe CDN assets. A production version may want vendored assets or a lockfile-backed package import.

Research Notes

The slider/menu taxonomy was based on public Bloodborne character creation references, especially:

  • Bloodborne Wiki slider tables
  • Bloodborne Face Details menu reference

During review, Base Skin Color was corrected: it should not be treated as a Basic Setup item. It belongs under Face Details / Skin Color / Makeup.

Recommended Next Development Steps

  1. Create a real calibration dataset of source faces, generated sliders, and in-game Bloodborne screenshots.
  2. Improve the estimator by tuning slider mappings against those screenshots.
  3. Add source-photo color sampling for skin, hair, brows, beard, lips, and pupils.
  4. Add an editable review mode so users can adjust generated values before exporting.
  5. Add visual side-by-side comparison between source image and in-game result screenshots.
  6. Consider a shareable "Souls sliders" export layout for posting results to the community.
  7. Add automated tests around slider generation so future tuning does not break menu coverage.
